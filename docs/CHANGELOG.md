# Changelog / Registro de decisiones

## 2026-10-17 – Planificación inicial
- **Stack**: TypeScript full-stack (React + Vite / NestJS) para compartir el motor de cálculo entre navegador y servidor.
- **BD**: PostgreSQL 16 (JSONB, triggers de inmutabilidad, versionado append-only) en lugar de MySQL.
- **Motor**: grafo reactivo de dependencias (DAG) con reglas de límites por severidad.
- **Diseño**: paleta de 5 colores sobrios; claro = texto negro, oscuro = texto blanco.
- **Pasos**: renumerados 0–16 (la solicitud original tenía dos "Paso 8" y dos "Paso 15").
- **Norma**: ANSI/TIA-942-C (2024); valores normativos parametrizados, a verificar con copia licenciada.
