# Daedalous

Plataforma para el **diseño, creación y visualización de Data Centers** basada en la norma **ANSI/TIA-942** (rev. C, 2024), con asistente guiado por pasos, motor de cálculo reactivo, versionado de proyectos, checklist asistido por IA y diseño 2D/3D sincronizado.

## Pilares
1. **Creación** – Asistente de 17 pasos (0–16), modulares, semi-independientes y conectados.
2. **Visualización** – Vista previa en vivo, 2D/3D, historial y línea de tiempo de cumplimiento TIA-942.
